제출용 — 확인 방법 4줄 (T04-C27)

① 어디로 가나요: GitHub Pages 주소의 "T04 오늘의 진짜 정보판" 카드와 카드 1 상세 표.
② 3단계 이내 무엇을 하나요: "정상 조회(라이브)" 클릭 → 카드 1의 값·출처 시각·조회 시각 확인 → 카드 3의 실패 5종 버튼 각각 클릭 후 복구 버튼 클릭.
③ 무엇이 보이면 통과인가요: 정상 시 9개 필드가 모두 표시되고, 실패 시 마지막 정상값(예: 22.2°C)이 유지되며 freshness=stale·error_code가 구분되어 보임. 복구 시 fresh/none으로 돌아오고 카드 4의 행 수가 1→2로 증가하며 delta=15가 표시됨(합성 재생 기준). 라이브 이틀 기록이 2건이면 카드 5에 어제 대비 변화가 표시됨.
④ 안 될 때 무엇이 보이나요: 네트워크 차단 시 freshness=stale·error_code=offline과 마지막 정상값의 fetched_at이 함께 표시됨.
